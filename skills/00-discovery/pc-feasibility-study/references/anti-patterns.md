# Anti-Pattern Notes

1. **Feasibility theater** -- Going through the motions when the decision is already made.
2. **Only checking technical feasibility** -- A working implementation may still cost more than its expected value or exceed operational capacity.
3. **Ignoring operational costs** -- Include maintenance, support, and migration costs; do not assume a universal build/run cost ratio.
4. **Binary thinking** -- "Can we build it?" is less useful than "What's the simplest version we can build?"
