# Input and Output Contract Notes

## Inputs

Use the current request/change, intended audience, existing canonical docs, and applicable route obligation. Read implementation/evidence only to establish the behavior being documented; no new upstream document is required just to start.

## Outputs

- **documentation-artifact** -- Updated authoritative guidance and its reader/owner, source references, verification limits, and authorized destination. When no update is needed and no output is required, record that decision in the existing handoff rather than create an empty document. Downstream users consume the guidance itself; a link to a local edit is not proof of external publication.
