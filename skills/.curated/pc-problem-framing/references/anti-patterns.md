# Anti-Pattern Notes

1. **Repeating intake** -- Intake already handled classification and routing. Framing should deepen the decision, not restart the entry gate.
2. **Premature architecture** -- Stay at the level of direction and trade-off. Leave system structure to `pc-system-design`.
3. **Infinite discovery interviews** -- Use the minimum questions needed to make a decision. If more information is required, route to research skills.
4. **Manufactured alternatives** -- Compare real choices. If approved constraints leave one direction, explain exclusions and unresolved decisions instead of adding implausible options.
