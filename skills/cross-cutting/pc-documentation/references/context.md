# Context Notes

Documentation is a cross-cutting concern that applies at every lifecycle phase. Good documentation reduces onboarding time, prevents knowledge loss, and enables async collaboration. The Diataxis framework provides a useful structure.

The current phase matrix uses conditional documentation triggers. Evaluate the selected phase and approved route rather than assuming a universal obligation. A required output cannot be waived merely by choosing fast-track. If no durable knowledge changes and no output is required, an explicit no-update decision is a valid completion outcome.

Existing documentation can satisfy a handoff when its scope, freshness, and discoverability still hold. Record new information where its next reader will look; avoid creating one document per skill invocation.
